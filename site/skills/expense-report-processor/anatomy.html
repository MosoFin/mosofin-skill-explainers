The structure of the expense report processor, and what it does

On main the skill is one 1,020-line file. The rewrite described here turns it into a 138-line card and seven reference files, and it keeps the original text. Two things set this skill apart. It checks each claim against the transactions already posted, so it finds a claim for a charge that the company card already paid. And it never supplies a mileage rate, a per-diem or a receipt threshold from memory. This page shows how the files connect, the run stage by stage, and the source behind each step. It also shows the three audit findings and how the audit fixed each one.
