The structure of the fixed asset register and depreciation skill, and what it does

The skill was one 1,102-line file. On main it is now a 161-line card and seven reference files. Commit ad090c2 made the split on 25 October 2026, and pull request #1 merged it on 26 October 2026. A bookkeeping-audit commit, 2d1ec7d, then changed the method on 27 October 2026. The skill computes book depreciation only, from the owner's own lives, salvage, method and convention. Tax depreciation is [manual] and goes to the tax preparer. It also reconciles in two directions and posts nothing. This page shows how the files connect, the run stage by stage, and the source behind each step. It also shows the audit: four commits with fixes on main, one check that main passes, and twelve open findings.
