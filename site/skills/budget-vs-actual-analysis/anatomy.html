The structure of the budget vs actual analysis, and what it does

On main the skill is a 154-line card and seven reference files. The split kept the original 922-line text. A bookkeeping-audit commit then changed the driver formulas, the materiality rule, the alignment checks and the closed-period check. Two things set this skill apart. It asks for the budget version by name and never picks one. And it never invents a cause: an unexplained variance stays open, with an owner who must give the cause. This page shows how the files connect, the run stage by stage, and the source behind each step. It also shows six audit findings, three fixed and three open.
