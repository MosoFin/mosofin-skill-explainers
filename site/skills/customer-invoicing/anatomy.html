The structure of the customer invoicing skill, and what it does

On main the skill is a 159-line card and seven reference files. Before the split it was one 899-line file. The split kept the original text, and a bookkeeping audit then changed eight points. Two things set this skill apart. It has two modes: it prepares new invoices, or it checks invoices that you already issued. And it creates, numbers, sends and posts nothing, so every invoice and every entry is a draft. This page shows how the files connect, the run stage by stage, and the source behind each step. It also shows the findings: three fixed on main, one that main never had, and four open.
